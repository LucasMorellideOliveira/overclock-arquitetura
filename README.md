# OVERCLOCK · a masmorra do chip

Jogo de estudo de **Arquitetura Computacional** (SPTech · SP3 MAT3). Cada capítulo do livro é um andar com um chefe, e cada luta tem três fases:

1. **Relâmpago**: dica e 4 alternativas, com o tempo encolhendo a cada acerto.
2. **Chuva de Termos**: os termos caem do teto e você precisa clicar no certo antes de ele chegar ao chão.
3. **Digita aí**: o golpe final, em que você escreve o termo sem alternativas.

Os conceitos que você erra voltam com mais frequência (repetição espaçada), e no fim de cada luta a **Lista de Vingança** mostra cada erro com a resposta certa. O progresso fica salvo no navegador.

- Perguntas: `data.js`
- Jogo: `game.js`, `style.css`, `index.html`

Não precisa de build: é só abrir o `index.html`.
